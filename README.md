# Hi, I'm Marco

I used to spend a lot of time handcrafting interactions, keeping MDN open, and getting CSS to behave. With AI in the loop, building interfaces feels different now. I still care about the small details: how an interface responds, where it gets in the way, and whether it feels natural to use.

Lately, I'm exploring [open-intelligent-ui](https://github.com/MMMarcinho/open-intelligent-ui), a protocol for turning model responses into interactive interfaces. I'm also working on a couple of DeepSeek Harness plugins: [dsh-canvas-workspace](https://github.com/MMMarcinho/dsh-canvas-workspace) for a canvas-based conversation view, and [dsh-flex-layout](https://github.com/MMMarcinho/dsh-flex-layout) for layouts that adapt to smaller screens.
